# แผน: เส้นเวลาโลก + Storyline + Treatment

สถานะ (2026-11-16): **ทำแล้วทุกเฟสในรุ่นแรก** — หน้า `/timeline` · ปฏิทินโลก + เวลาของ lore · สร้าง/ลากย้าย/แก้/ลบ + ซูม ·
storyline (lore ชนิดเหตุการณ์ + ผู้เกี่ยวข้อง + `lore_entries.scene_ids`) · แผง treatment (กฎใน `lib/world-consistency.ts` + ตัวตรวจเดิม)

ส่วนที่ตัดสินต่างจากแผนเดิม / ยังไม่ทำ:
- เหตุการณ์ในโลกใช้ `lore_entries` (type `event`) ไม่สร้างตารางใหม่ · ผู้เกี่ยวข้องใช้ `related_character_ids` / `related_location_ids` เดิม
- ของที่ผูกกับบท (life event, เข้ากลุ่ม, ได้พลัง) ยังวางเป็นตำแหน่งประมาณตามฉากแรกของบท ไม่ได้เพิ่มคอลัมน์เวลาในโลก
- แกนเป็นช่องตามลำดับ (ไม่ใช่สเกลเวลา) · ลากวางได้แค่ "ลงช่อง" ยังวางระหว่างช่องไม่ได้
- `ChronoTimelineSheet` ยังไม่ถอด · ยังไม่มีปุ่ม "ดูบนเส้นเวลา" จากกระดานพล็อต/หน้า Lore
- treatment ยังไม่มีส่วน AI (แรงจูงใจ/เหตุ-ผล) และยังไม่มีกฎ "ใช้พลัง/ไอเทมก่อนได้มา"

(ด้านล่างคือแผนเดิมตอนออกแบบ 2026-11-07 ถึง 2026-11-15)

## 1. นิยามที่ใช้ทั้งเอกสาร

| คำ | ความหมาย | มีแล้วไหม |
|---|---|---|
| **Plotline** | เรื่องถูก**เล่า**ยังไง: ผ่าน POV/สถานการณ์ไหน ตามลำดับที่คนอ่านเห็น (บท → ฉาก) | มี (หน้าโครงเรื่อง) |
| **Storyline** | ณ ช่วงเวลานั้นในโลก**เกิดอะไรขึ้นบ้าง** รวมถึงเรื่องที่ไม่ได้อยู่ในฉาก | ยังไม่มี |
| **Timeline** | แกนเวลาของโลก มีปฏิทินของตัวเอง ลากย้อนไปถึงประวัติศาสตร์และ lore | มีบางส่วน กระจายอยู่ |
| **Treatment** | ทำให้ทุกอย่าง**สมเหตุสมผลต่อกัน** = ชั้นตรวจความสอดคล้องข้าม plotline / storyline / timeline / lore **ไม่ใช่**เอกสารสรุปเรื่องแบบ treatment ภาพยนตร์ | ยังไม่มี (มีกฎบางตัวกระจายอยู่) |

Plotline กับ storyline คือคู่ syuzhet (ลำดับที่เล่า) กับ fabula (ลำดับที่เกิดจริง)

## 2. ของเดิมที่เกี่ยวข้อง

| ชิ้น | ไฟล์ | ทำอะไรอยู่ | ข้อจำกัด |
|---|---|---|---|
| กระดานพล็อต | `components/project/timeline/timeline-board.tsx` (`TimelineBoard`) | เรียงฉากตาม**ลำดับเล่า** | ชื่อในโค้ดเป็น timeline แต่จริง ๆ คือ plotline |
| Chrono sheet | `components/project/timeline/chrono-timeline-sheet.tsx` | ลิสต์ฉากเรียงตาม `storyTimeIndex` ลากจัดลำดับ, Day N, ไฮไลต์ flashback | อยู่ใน sheet แคบ ๆ มีแค่ฉาก ไม่มี lore |
| Lore timeline | `components/project/worldbuilding/lore-timeline.tsx` | lore เรียงตาม `eras.orderIndex` → `orderInEra` | ไม่มีเวลาเป็นตัวเลข ไม่เห็นฉาก |
| ตรวจความขัดแย้ง | `server/timeline-conflicts.ts`, Consistency Guardian, คำเตือนสมุดปม | กฎ deterministic | กระจายกันอยู่สามที่ |
| ตัวช่วยวันที่ | `lib/story-date.ts` | `storyDate` = วันที่ N นับจาก `novels.timelineEpoch` แสดงเป็นปฏิทินพุทธ | **clamp ไว้ ±100 ปี** (`STORY_DATE_MIN/MAX`) และผูกกับปฏิทินจริง ใช้กับ lore พันปีไม่ได้ |

ช่องเวลาใน DB ตอนนี้:
- `timeline_events`: `eventDate` (text ป้ายแสดง), `storyTimeIndex` (ลำดับ), `storyDate` (เลขวัน), `eraId`
- `novels.timelineEpoch` (วันจริงของ Day 1)
- `eras`: มีแค่ `orderIndex` ไม่มีปีเริ่ม/จบ
- `lore_entries`: `eraId` + `orderInEra` + `orderIndex` ไม่มีเวลา
- `character_life_events.chapterId`, `character_states.noteId`, `character_factions` / `character_powers` (start/endChapterId) ผูกกับ**ลำดับเล่า** ไม่ใช่เวลาในโลก

## 3. โครงหน้า (IA) — ตกลงแล้ว

เพิ่มหน้าใหม่ **"เส้นเวลา"** (`/dashboard/project/[id]/timeline`) ใน sidebar กลุ่ม "เขียน" ต่อจาก "โครงเรื่อง"

```
เขียน
  ภาพรวม
  โครงเรื่อง     plotline: กระดาน / ปมเรื่อง (ของเดิม)
  เส้นเวลา  ★    timeline + storyline
  ไอเดีย
สร้างโลก
  ตัวละคร / กลุ่มอำนาจ / สร้างโลก / ระบบพลัง / แผนผังโลก / นำเข้าไบเบิล
วิเคราะห์
  สถิติ
  treatment ★ (เฟส 4 — ตำแหน่งยังไม่เคาะ)
```

เหตุผลที่เป็นหน้าแยกไม่ใช่แท็บที่ 3 ในโครงเรื่อง: เส้นเวลาเป็นของ "โลก" พอ ๆ กับ "เรื่อง" ถ้าอยู่ใต้โครงเรื่อง lore จะดูเป็นของแถม · วางติดโครงเรื่องเพราะสองหน้านี้จะถูกสลับไปมาบ่อยที่สุด

### เจ้าของข้อมูล (แก้ที่เดียว เห็นได้หลายที่)

| ข้อมูล | แก้ไขที่ | เห็นที่ |
|---|---|---|
| ยุค + ปฏิทิน | เส้นเวลา (ตั้งค่าปฏิทิน) | เส้นเวลา, Lore |
| เนื้อหา lore | สร้างโลก → Lore | เส้นเวลา (จุดบนแกน) |
| เวลาของ lore | ลากบนเส้นเวลา หรือกรอกในฟอร์ม lore | ทั้งสองที่ |
| เนื้อหาฉาก + ลำดับเล่า | โครงเรื่อง → กระดาน | เส้นเวลา (เลน "เล่าใน") |
| เวลาของฉาก | เส้นเวลา | กระดาน (ป้ายวันที่บนการ์ด) |
| เหตุการณ์นอกจอ | เส้นเวลา | เส้นเวลา |
| ตัวละคร / กลุ่ม | สร้างโลก | เส้นเวลา (เป็นเลน) |

### ของเดิมจะเป็นยังไง
- `ChronoTimelineSheet`: หน้าใหม่ทำแทนได้ครบ ปุ่มบนกระดานเปลี่ยนเป็น "ดูบนเส้นเวลา" (พาไปหน้าใหม่ เลื่อนไปที่ฉากนั้น) เก็บไฟล์ไว้จนหน้าใหม่เสถียร แล้วค่อยถอด
- `LoreTimeline`: **เก็บไว้** (มีกลุ่ม/ลำดับชั้น lore ที่หน้าเส้นเวลาไม่ทำ) เพิ่มปุ่ม "ดูบนเส้นเวลา"
- `TimelineBoard`: ไม่แตะ ควรเปลี่ยนชื่อในโค้ดเป็น `PlotBoard` ภายหลัง (งานแทรก ไม่อยู่ในแผนนี้)

## 4. หน้าเส้นเวลา (UI)

```
[ยุค|ปี|เดือน|วัน]  zoom   ปฏิทิน: ยุคเพลิง ⚙                       [+ เหตุการณ์]
──────────────────────────────────────────────────────────────────────────────
แกนเวลา    │ ยุคแรก ──│≈300 ปี│ ยุคเพลิง ปี 1 ──── 340 ── 341 ── 342 ─────────►
โลก / lore │ ◆ กำเนิดเวทย์    [ สงคราม 100 ปี ]           ◆ ราชาสวรรคต
อลิน       │                          ●─────●───────●──●
เคน        │                     ●─────────○─────●          ○ = นอกจอ
กลุ่มเงา    │                          ○─────○──────○
เล่าใน     │                     [บท 2 ↶]  [บท 1]   [บท 3]
──────────────────────────────────────────────────────────────────────────────
ยังไม่ระบุเวลา (3):  คำทำนายของหอคอย · ฉาก: งานเลี้ยงในวัง · เคนพบดาบ
```

- **แกนนอน = เวลาในโลก** ซูมได้ ยุค → ปี → เดือน → วัน
- **ช่วงว่างยาว ยุบให้แคบ** พร้อมป้าย "≈ 300 ปี" ไม่อย่างนั้นปัจจุบันของเรื่องจะเหลือจุดเดียว
- **เลนแบ่งตามหมวดของแอป** (ตรงกับเมนู/แท็บที่ผู้ใช้รู้จัก) แต่ละหมวดพับเป็นแถวเดียว หรือกางเป็นเลนย่อยได้ · ยุคเป็นแถบสีพื้นหลังของแกน

  | หมวด (มาจากหน้า) | เลนย่อยเมื่อกาง | เหตุการณ์ที่วางบนแกน | ข้อมูลเวลาตอนนี้ |
  |---|---|---|---|
  | โครงเรื่อง | ต่อบท | ฉาก (↶ เมื่อเป็น flashback) | `storyDate` / `storyTimeIndex` ✓ |
  | Lore | ต่อ lore group | lore เป็น ◆ หรือแถบถ้าเป็นช่วง | แค่ `eraId` + ลำดับในยุค |
  | ตัวละคร | ต่อตัวละคร | เกิด/ตาย, life events, ฉากที่ปรากฏ (● ในฉาก, ○ นอกจอ) | life events ผูกกับ**บท** (`chapterId`) |
  | กลุ่มอำนาจ | ต่อกลุ่ม | ก่อตั้ง, สมาชิกเข้า/ออก | `character_factions` start/endChapterId (ผูกกับบท) |
  | ระบบพลัง | ต่อพลัง | ตัวละครได้พลัง/เลื่อนระดับ | `character_powers` / `power_levels` (ผูกกับบท) |
  | สถานที่ | ต่อสถานที่ | lore ระดับสถานที่, ฉากที่เกิดที่นั่น | ผ่าน lore (`scope=location`) และฉาก |
  | ไอเทม | ต่อไอเทม | ได้มา/เปลี่ยนมือ | ยังไม่มีข้อมูลเวลาเลย |

- ของที่ผูกกับ**บท** (ไม่ใช่เวลาในโลก) เฟส 1 จะวางที่ตำแหน่งเวลาของฉากแรกในบทนั้น ติดป้าย "ประมาณ" · เฟส 3 ค่อยให้ผูกกับเวลาในโลกจริง
- หมวดที่ไม่มีเหตุการณ์ที่มีเวลา แสดงแถวว่างพร้อมข้อความ ไม่ซ่อน เพื่อให้รู้ว่าหมวดนี้ยังไม่ได้ลงเวลา
- ปุ่ม "เลน" ใช้เลือกว่าจะโชว์หมวดไหน และเลนย่อยไหน (เช่น ตัวละคร 2 จาก 8) จำค่าไว้ต่อนิยายใน localStorage
- **ลากซ้าย/ขวา = เปลี่ยนเวลา** snap ตามระดับซูม · คลิก = รายละเอียด · ดับเบิลคลิกพื้นที่ว่าง = สร้างเหตุการณ์ ณ เวลานั้น
- **ถาด "ยังไม่ระบุเวลา"** ลากขึ้นแกนภายหลังได้

## 5. ปฏิทินและโมเดลเวลา

ต้องมีปฏิทินของโลก (ไม่ใช่แค่ก่อน/หลัง) เพราะ lore ต้องอยู่บนแกนเดียวกัน

**ปฏิทิน** (ต่อนิยาย 1 ชุด ผู้เขียนนิยามเอง):
- ยุค: ใช้ `eras` เดิม เพิ่มปีเริ่ม (และปีจบถ้ามี) เช่น "ปีที่ 342 แห่งยุคเพลิง"
- โครงปี: จำนวนเดือน, ชื่อเดือน, จำนวนวันต่อเดือน · ไม่ตั้ง = 12 เดือน × 30 วัน
- ทางเลือก "ปฏิทินจริง": สำหรับนิยายโลกจริง ใช้ `timelineEpoch` เดิม

**เวลาของแต่ละเหตุการณ์**:
- เก็บเป็นตัวเลขเดียวบนแกน (เลขวันนับจากจุดศูนย์ของโลก) + **ความละเอียด** (ยุค/ปี/เดือน/วัน) เพื่อไม่ให้แสดง "วันที่ 1 เดือน 1" กับสิ่งที่รู้แค่ปี
- ไม่รู้เวลา = ใช้ลำดับก่อน/หลังเป็นทางสำรอง (เช่น "หลังการล่มสลาย") ระบบเรียงให้

**ข้อควรระวัง**:
- `lib/story-date.ts` clamp ไว้ ±100 ปี และใช้ `Intl` ปฏิทินพุทธ ต้องมีตัวแปลงใหม่สำหรับปฏิทินของโลก อย่าขยาย clamp ของเดิมเฉย ๆ
- แก้ปฏิทินภายหลัง (เช่น เปลี่ยนวันต่อเดือน) ตำแหน่งที่เก็บเป็นเลขวันจะแสดงเป็นวันที่ต่างไป ต้องเตือนก่อนบันทึก

## 6. ข้อมูล (แนวคิด ยังไม่ใช่ schema จริง)

กติกา: **เพิ่มอย่างเดียว ไม่ลบหรือเปลี่ยนความหมายคอลัมน์เดิม** (ฐาน Neon ใช้ร่วมกัน · ใช้ `npm run db:push` เท่านั้น)

| ของใหม่ | ใช้ทำอะไร |
|---|---|
| ปฏิทินต่อนิยาย (ตารางใหม่ หรือ jsonb บน `novels`) | ชื่อเดือน, วันต่อเดือน, จุดศูนย์ |
| `eras` + ปีเริ่ม/จบ | วางยุคบนแกน |
| `lore_entries` + เวลา + ความละเอียด (+ เวลาจบถ้าเป็นช่วง) | วาง lore บนแกน |
| `timeline_events` + ความละเอียด | ฉากใช้ `storyDate` ต่อได้ แค่ต้องรู้ว่าแม่นแค่ไหน |
| เหตุการณ์ในโลก (ตารางใหม่ — เฟส 3) | storyline: เหตุการณ์นอกจอ + ผู้เกี่ยวข้อง + สถานที่ |
| ผูกฉาก ↔ เหตุการณ์ (เฟส 3) | ฉากหนึ่งเปิดให้เห็นเหตุการณ์ได้หลายตัว |

ยังต้องเคาะ: เหตุการณ์ในโลกเป็นตารางใหม่ หรือขยาย `timeline_events` ให้มีชนิด "นอกจอ" (ทางหลังกระทบกระดานพล็อตที่ query ตารางนี้อยู่ทุกที่)

## 7. เฟส

### เฟส 1 — หน้าเส้นเวลาแบบอ่านอย่างเดียว (ไม่แตะ schema)
- เพิ่มหน้า + เมนู sidebar
- วาง eras (ตาม `orderIndex`), lore (ตาม `orderInEra`), ฉาก (ตาม `storyDate` หรือ `storyTimeIndex`) บนแกนเดียว
- ยังไม่มีปฏิทิน: แกนเป็น "ยุค" + "Day N" แบบที่ chrono sheet ทำ
- **เป้า**: ดูว่าเลย์เอาต์เลน + ยุบช่วงว่าง + ถาดไม่ระบุเวลา ใช้งานได้จริงไหม ก่อนลงทุน schema

### เฟส 2 — ปฏิทิน + เวลาของ lore + ลากแก้ได้
- ตั้งค่าปฏิทิน, ปีของยุค, เวลาของ lore (schema เพิ่มอย่างเดียว)
- ลากเปลี่ยนเวลาบนแกน · ซูมระดับปี/เดือน/วัน
- ปุ่ม "ดูบนเส้นเวลา" บนกระดานและหน้า Lore
- ถอด `ChronoTimelineSheet` เมื่อหน้าใหม่ครอบคลุมครบ

### เฟส 3 — Storyline
- เลนต่อตัวละคร/กลุ่ม (เลือกได้ว่าจะโชว์เลนไหน)
- เหตุการณ์นอกจอ + ผูกฉาก ↔ เหตุการณ์
- ย้ายข้อมูลที่ผูกกับบท (`character_factions`, `character_powers`, `character_life_events`) มาอ้างเวลาในโลกผ่านฉาก (เพิ่มคอลัมน์ ไม่ลบของเดิม)

### เฟส 4 — Treatment (ตรวจความสมเหตุสมผล)
- ย้ายกฎเดิมมารวมที่เดียว: `server/timeline-conflicts.ts`, Consistency Guardian, คำเตือนสมุดปม
- กฎใหม่ (deterministic): อยู่สองที่พร้อมกัน · เดินทางเร็วเกินระยะ (`location_connections`) · โผล่ก่อนเกิด/หลังตาย · อ้าง lore ที่ยังไม่เกิด · ใช้พลัง/ไอเทมก่อนได้มา · flashback ขัดกับเหตุการณ์จริง · ปมเฉลยด้วยสิ่งที่ยังไม่เกิด
- AI (กดเรียกเองเท่านั้น): แรงจูงใจขัดกับเหตุการณ์ก่อนหน้า, เหตุ-ผลไม่ต่อกัน

## 8. Edge case

| เคส | ทำยังไง |
|---|---|
| นิยายใหม่ ไม่มียุค ไม่มีปฏิทิน | แกน "Day 1, 2, 3" + ปุ่ม "ตั้งปฏิทินโลก" |
| ฉากมีแค่ `storyTimeIndex` ไม่มีวันที่ | วางเรียงต่อกันตามลำดับ ป้าย "ประมาณ" |
| ฉาก/lore ไม่มีเวลาเลย | ถาด "ยังไม่ระบุเวลา" |
| lore หลายร้อยรายการ | ระดับยุครวมจุดใกล้กันเป็น "+12" กดขยาย |
| ช่วงว่างหลายร้อยปี | ยุบแกน + ป้าย "≈ N ปี" |
| แก้ปฏิทินภายหลัง | เตือนก่อนบันทึกว่าวันที่ที่แสดงจะเปลี่ยน |
| ลำดับเล่าสวนลำดับเวลา | ↶ บนเลน "เล่าใน" (ใช้ logic flashback เดิมของ chrono sheet) |

## 9. ไม่ได้ทำในแผนนี้

- Mobile (ทั้งแอปยัง desktop-first)
- AI ที่วางเหตุการณ์หรือเดาเวลาให้อัตโนมัติ (ขัดหลัก AI opt-in)
- ปฏิทินหลายชุดในเรื่องเดียว (เช่น สองอาณาจักรนับปีต่างกัน) — เก็บไว้คิดถ้ามีคนต้องการจริง
- ภาพตัวอย่างฉาก (ASCII visual gateway พักไว้แยก)
- เปลี่ยนชื่อ `TimelineBoard` → `PlotBoard`

---

## 10. คำถามที่ยังเปิด

1. เหตุการณ์ในโลก (เฟส 3): ตารางใหม่ หรือขยาย `timeline_events`
2. หน้า treatment (เฟส 4) อยู่ที่ไหน: หน้าแยกใต้ "วิเคราะห์" หรือเป็นแผงในหน้าเส้นเวลา
3. หมวดไหนกางไว้เป็นค่าเริ่มต้น (เสนอ: โครงเรื่อง + Lore กาง, ที่เหลือพับ) และตัวละครโชว์ใครบ้าง (ทั้งหมด หรือแค่ POV)
4. ปฏิทิน: เก็บเป็นตารางใหม่ หรือ jsonb บน `novels`
